# Domain Documentation Rules

- **Layout**: Single-context repository.
- **Glossary**: `CONTEXT.md` at root.
- **Architecture Decisions**: `docs/adr/*.md`.

## Consumer Rules

- Read `CONTEXT.md` to learn the ubiquitous language and domain concepts.
- Consult `docs/adr/` before making architectural changes.
- Record hard-to-reverse architectural decisions as new ADRs.
