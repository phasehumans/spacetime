# Issue Tracker

Issues live in GitHub Issues for `phasehumans/spacetime` and are managed via `gh` CLI.

## Workflows

### Reading issues

- List open issues: `gh issue list`
- View specific issue: `gh issue view <number>`

### Writing issues

- Create issue: `gh issue create --title "<title>" --body "<body>" --label "ready-for-agent"`
- Close issue: `gh issue close <number> --comment "<comment>"`
